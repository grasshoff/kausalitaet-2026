Kapitel 1

Mills unerfüllbare Forderung

Wer eine Ursache durch Vergleich finden will, vergleicht Fälle, die sich in dem fraglichen Faktor unterscheiden. John Stuart Mill verlangte dafür Fälle, die »every circumstance in common save one« haben (Mill 1843, Buch III, Kap. 8) (Bd. I, Abschn. 3.3).

Zwei Patienten unterscheiden sich in Alter, Erbanlagen, Ernährung, Schlaf und in tausend weiteren Hinsichten. Verlangte kausales Schließen, dass all das übereinstimmt, so hätte keine klinische Studie je ein Ergebnis begründet.

Kapitel 2

Ein Konjunkt schaltet einen Cluster ab

Was ein Vergleich verhindern muss, ist nicht, dass Hintergrundfaktoren variieren. Es ist, dass ein konkurrierender Cluster in dem einen Fall ausgelöst wird und im anderen nicht. Dann spiegelt der Vergleich das Kommen und Gehen dieses Clusters wider, nicht den geprüften Faktor.

Ein Cluster ist eine Konjunktion. Fehlt eines ihrer Glieder zuverlässig, ist die ganze Konjunktion falsch. Schließt die Studie Patienten mit Neigung zur Spontanremission aus, ist der untere Cluster abgeschaltet. Die Immunantwort darf dann von Patient zu Patient beliebig schwanken, ohne irgendeine Wirkung auf die Genesung oder auf den Vergleich.

Beim Cluster der Behandlung gilt das Umgekehrte: Sein Partner, die Aufnahme des Mittels, muss in allen Fällen vorliegen, sonst misst der Vergleich die schwankende Aufnahme mit. Dafür sorgen das Protokoll der Verabreichung und die Kontrolle der Einnahme.

Das Ziel ist also nicht, möglichst viel konstant zu halten. Es ist, für jeden konkurrierenden Cluster das eine Glied zu finden, das sich am leichtesten abwesend halten lässt. Die Homogenitätsforderung zu minimieren ist kein Zugeständnis an die Praxis; es macht effizientes Experimentieren erst möglich.

Kapitel 3

Wo sich nichts abschalten lässt

Nicht jeder konkurrierende Cluster hat ein Glied, das sich abwesend halten lässt. Für solche Cluster gibt es die Randomisierung. Sie schaltet den Cluster nicht ab; nichts in einer Studie an Menschen könnte das. Sie macht sein Auslösen unabhängig von der Zuteilung zur Behandlung: Er wird in beiden Armen gleich häufig ausgelöst.

Daraus ergeben sich zwei verschiedene Homogenitätsforderungen für zwei verschiedene Schlüsse.

  • Gate A, für das Ablesen einer ganzen Theorie aus einer Tabelle: Jedes verborgene Bündel von Hintergrundbedingungen hat im ganzen Feld denselben Wahrheitswert. Jede widersprüchliche Konfiguration widerlegt das; kommt keine vor, ist nur keine Verletzung gefunden.
  • Gate B, für einen einzelnen Vergleich zweier Arme: Kein konkurrierendes Bündel wird mit dem geprüften Faktor unterschiedlich häufig ausgelöst. Dafür sorgen Ausschlusskriterien, Protokoll und Randomisierung.

Eine randomisierte Studie besteht Gate B und verfehlt in der Regel Gate A. Das ist kein Mangel. Sie will nicht jeden Fall erklären, sondern einen Faktor isolieren. Wie weit sie damit kommt, zeigt die Statin-Studie.
